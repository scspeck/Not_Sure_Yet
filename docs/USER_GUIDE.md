# User guide

1. **Load data.** Upload CSV or load the example.
2. **Map fields.** Assign latitude/longitude first, then useful taxonomy, geography, date, identifier, and descriptive fields.
3. **Configure traits.** Choose numeric, categorical, or text fields. Numeric filters are independent of `Size by`.
4. **Build map.** Left-click points for information; right-click to select/deselect.
5. **Filter.** Use taxonomy/geography, year, global search, and trait filters. `All values` should not reduce the dataset.
6. **Visualize.** Toggle clustering or record-density heatmap. Density is record density, not abundance.
7. **Navigate.** Use scale, cursor coordinates, full screen, place search, and zoom-to-filtered.
8. **Spatially select.** Right-click records or draw a rectangle/polygon around currently visible records.
9. **Export.** Export filtered or selected records as CSV or GeoJSON.
10. **Interpret carefully.** Validate important findings against authoritative data and consider sampling, digitization, missing-data, taxonomy, and georeferencing biases.
