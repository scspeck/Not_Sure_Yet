Trait MMAP

Mapper for Mammals and Parasites · upload-first v0.2.1
Upload a georeferenced mammal dataset, choose the biological traits you want to explore, filter records interactively, select them spatially, and export research-ready subsets. Files are processed locally in your browser.
1. Load a dataset
No dataset loaded.
2. Map core fields
Latitude and longitude are required. Other mappings improve popups, search, summaries, and temporal filtering.
3. Choose trait fields
Trait MMAP infers a useful filter type for each column. Check the fields you want available as interactive traits. Numeric fields become searchable numeric filters (exact value, minimum, and maximum) and may also be used for point-size visualization. Categorical fields receive value filters; text fields receive contains-search filters.

Spatial selection
Left-click a point to inspect it. Right-click a point to add/remove it from the selection. Use the polygon tool on the map to select all currently visible records inside an area.
Export
Exports preserve every original column from the uploaded CSV. Trait MMAP adds only a few helper columns describing selection and parsed coordinates/year.
Dataset controls
Trait MMAP is a client-side research interface. Uploaded files are not transmitted by this application. Always retain and cite the authoritative source of your underlying data.
