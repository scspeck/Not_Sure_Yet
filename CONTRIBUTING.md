# Contributing to Trait MMAP

Bug reports, documentation improvements, reproducible test cases, and focused feature proposals are welcome.

For bugs, include the Trait MMAP version/commit, browser and operating system, data source, steps to reproduce, expected behavior, observed behavior, and browser-console errors when available. Never post sensitive locality data, personal information, restricted datasets, or API keys in public issues.

Before code changes, review `docs/TESTING.md`. Major changes should have an issue and should preserve the upload-first design. Optional external services must not prevent users from working with their own uploaded data.
